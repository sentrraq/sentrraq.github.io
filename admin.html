🔗 GitHub Auto-Publish

Hubungkan admin ke repo GitHub agar perubahan produk langsung live ke website.

1
Buka github.com/settings/tokens/new, isi nama token (misal: sentraq-admin), centang repo, klik Generate token, lalu copy tokennya.
2
Paste token di field “GitHub Token” di bawah. Isi username GitHub dan nama repo-mu (misal: sentraq dan sentraq.github.io).
3
Klik Simpan & Test. Kalau muncul ✓ Terhubung — selesai! Klik Publish ke GitHub setiap kali ada perubahan produk.

🔐 Ganti Password Admin

Password default: sentraq123 — segera ubah setelah pertama login.

⚠ Danger Zone

Hapus token GitHub dan konfigurasi dari browser ini. Data produk tidak akan terpengaruh.
