Download & Upload Manual

Tidak perlu token GitHub. Cukup download file JSON, lalu upload ke repositori melalui browser atau GitHub Desktop.

1
Klik Download products.json untuk mengunduh data produk terbaru.
2
Buka repositori GitHub kamu, navigasi ke file products.json di root folder.
3
Klik ikon pensil (Edit) → "Upload file" → pilih file yang baru didownload, atau drag & drop ke halaman GitHub.
4
Klik Commit changes. Website otomatis update dalam beberapa detik.
