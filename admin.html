Konfigurasi GitHub untuk auto-publish produk.

GitHub Auto-Publish

Hubungkan admin ke repo GitHub kamu agar perubahan produk langsung ter-publish ke website tanpa manual upload.

1
Buat Personal Access Token di GitHub:
github.com/settings/tokens/new
Centang permission: repo → Save token.
2
Isi form di bawah dengan token, username GitHub, dan nama repo kamu.
3
Klik Simpan, lalu klik Publish ke GitHub di topbar kapanpun ada perubahan produk.

Disimpan di browser (localStorage). Tidak pernah dikirim ke server selain GitHub API.

Ganti Password Admin

Password disimpan sebagai SHA-256 hash di browser kamu.

⚠ Danger Zone

Reset semua data admin di browser ini (token, settings). Produk tidak akan terhapus dari GitHub.

Tambah Produk

Dikosongkan = otomatis dari nama + harga

Upload dari device atau paste URL gambar.
