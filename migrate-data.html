Migrasi Data ke Supabase

Import produk dari products.json lama ke database Supabase. Jalankan sekali saja.

Cara Penggunaan

1
Buka file products.json yang ada di repo GitHub kamu, copy seluruh isinya.
2
Paste konten JSON ke kotak di bawah ini.
3
Klik Import ke Supabase. Setiap produk akan dimasukkan satu per satu.
4
Setelah selesai, buka Admin Dashboard untuk memastikan semua produk masuk dengan benar.

⚠️ Produk yang memiliki ID yang sama akan dilewati (tidak ditimpa) untuk menghindari duplikasi.
